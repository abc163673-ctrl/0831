# 개인 프로필 페이지 제작 문서

## 1. 목표

HTML, CSS, JavaScript만 사용해 개인의 소개와 작업물을 보여 주는 반응형 프로필 페이지를 만든다. 방문자는 한 화면에서 기본 정보, 기술, 프로젝트, 연락 방법을 쉽게 확인할 수 있어야 한다.

## 2. 대상 사용자

- 포트폴리오를 확인하는 채용 담당자 및 협업자
- 개인의 관심사와 기술을 살펴보는 방문자

## 3. 페이지 구성

| 섹션 | 포함 내용 | 목적 |
| --- | --- | --- |
| 헤더 | 이름 또는 로고, 메뉴, 다크 모드 버튼 | 페이지 이동 및 첫인상 제공 |
| 히어로 | 프로필 이미지, 한 줄 소개, CTA 버튼 | 정체성과 목표를 빠르게 전달 |
| 소개 | 자기소개, 관심 분야, 짧은 이력 | 배경과 강점 설명 |
| 기술 | 사용 가능한 기술 목록과 숙련도 | 기술 역량 표현 |
| 프로젝트 | 썸네일, 설명, 사용 기술, 링크 | 대표 작업물 소개 |
| 연락처 | 이메일, GitHub, 블로그, SNS | 협업 및 문의 연결 |
| 푸터 | 저작권, 상단 이동 버튼 | 페이지 마무리 |

## 4. 권장 파일 구조

```
frontend/
  index.html
  css/
    style.css
  js/
    main.js
  assets/
    images/
```

## 5. HTML 설계

- 의미 있는 태그를 사용한다: `header`, `nav`, `main`, `section`, `article`, `footer`.
- 메뉴 링크는 각 섹션의 `id`로 연결한다.
- 프로필 이미지에는 내용을 설명하는 `alt` 텍스트를 넣는다.
- 프로젝트 카드는 반복 가능한 `article` 구조로 작성한다.
- 외부 링크에는 새 탭 안내를 위해 `target="_blank"`와 `rel="noopener noreferrer"`를 적용한다.

## 6. CSS 설계

- 모바일 우선 방식으로 작성하고, 넓은 화면에서는 Grid 또는 Flexbox로 배치한다.
- 공통 색상, 여백, 글자 크기는 CSS 변수로 관리한다.
- 본문 최대 너비를 제한해 읽기 쉬운 레이아웃을 유지한다.
- 버튼, 메뉴, 프로젝트 카드에 자연스러운 hover/focus 상태를 제공한다.
- 키보드 사용자가 현재 위치를 알 수 있도록 `:focus-visible` 스타일을 적용한다.
- 다크 모드는 `data-theme="dark"` 속성 또는 `dark` 클래스로 색상 변수만 바꾸는 방식으로 구현한다.

## 7. JavaScript 기능

- 모바일 메뉴 열기/닫기
- 메뉴 클릭 시 해당 섹션으로 부드럽게 이동
- 다크 모드 전환 및 선택값 `localStorage` 저장
- 스크롤 위치에 따른 현재 메뉴 강조
- 상단 이동 버튼 표시 및 동작
- 필요 시 프로젝트 데이터를 배열로 관리해 카드 자동 생성

## 8. 디자인 방향

- 배경은 밝고 단정하게, 강조색은 한 가지로 제한한다.
- 첫 화면에는 이름, 역할, 핵심 문장, 연락 버튼을 우선 배치한다.
- 프로젝트 카드는 이미지 비율과 버튼 위치를 통일한다.
- 글꼴 크기와 대비를 충분히 확보해 읽기 편하게 만든다.
- 움직임은 200~300ms 내외의 짧은 전환 효과로 제한한다.

## 9. 제작 순서

1. `index.html`에 페이지 섹션과 콘텐츠 뼈대를 작성한다.
2. `style.css`에 색상 변수, 공통 레이아웃, 반응형 스타일을 구현한다.
3. `main.js`에 메뉴, 테마, 스크롤 관련 상호작용을 추가한다.
4. 실제 프로필 사진, 소개글, 기술, 프로젝트 링크로 콘텐츠를 교체한다.
5. 모바일·태블릿·데스크톱 화면과 키보드 탐색을 확인한다.

## 10. 준비할 콘텐츠

- 이름, 직무 또는 희망 분야, 한 줄 소개
- 프로필 사진 또는 대체 일러스트
- 자기소개와 주요 경험
- 기술 목록과 숙련도 기준
- 프로젝트 2~4개: 제목, 설명, 이미지, 저장소/배포 링크
- 이메일 및 외부 프로필 링크

## 11. 완료 기준

- 모든 메뉴가 올바른 섹션으로 이동한다.
- 작은 화면에서도 가로 스크롤 없이 읽을 수 있다.
- 다크 모드 선택이 새로고침 후에도 유지된다.
- 이미지와 링크에 접근성 정보를 제공한다.
- 프로젝트 및 연락처 정보가 실제 정보로 교체되어 있다.
